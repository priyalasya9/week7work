# 🧪 EXPERIMENT: EBS Volume Creation, Mounting & Snapshot (Week 2)

---

# 🎯 AIM

To create and attach an EBS volume to an EC2 instance, mount it permanently in Linux, and create a snapshot for backup.

---

# 🧰 PREREQUISITES

* AWS Account login
* Running Linux EC2 instance
* SSH / PuTTY access to EC2
* Same Availability Zone for EC2 and EBS

(EBS must be in same AZ as EC2, otherwise it won’t attach.)

---

# 🔹 PART A — CREATE AND ATTACH EBS VOLUME

## Step 1: Login to AWS Console

1. Open AWS Management Console
2. Go to **EC2 Dashboard**

---

## Step 2: Create EBS Volume

1. Click **Volumes** (Left panel)
2. Click **Create Volume**
3. Configure:

   * Volume Type: gp3 (or gp2)
   * Size: 8 GB or 10 GB
   * Availability Zone: SAME as EC2 instance
4. Click **Create Volume**

---

## Step 3: Attach Volume to EC2

1. Select the created volume
2. Click **Actions → Attach Volume**
3. Choose your EC2 instance
4. Device name:

   ```
   /dev/xvdf
   ```
5. Click **Attach**

Volume is now attached to the instance.

---

# 🔹 PART B — VERIFY ATTACHED DISK IN EC2

## Step 4: Connect to EC2 Instance

Connect using:

* PuTTY (SSH)
  OR
* AWS Connect terminal

---

## Step 5: Check Available Disks

Run:

```bash
lsblk
```

Observation:

* Root disk → xvda
* New EBS disk → xvdb / nvme1n1 / xvdbf

This confirms EBS is attached.

---

# 🔹 PART C — CREATE PARTITION ON EBS VOLUME

## Step 6: Create Partition using fdisk

(Use your disk name from lsblk)
Example:

```bash
sudo fdisk /dev/xvdbf
```

Inside fdisk:

* Press `n` → New partition
* Press `p` → Primary
* Press Enter (default sector)
* Press Enter (default size)
* Press `w` → Write and exit

---

## Step 7: Refresh Partition Table

```bash
sudo partprobe
lsblk
```

Now you should see:

```
xvdbf1 (new partition)
```

---

# 🔹 PART D — FORMAT THE EBS VOLUME

## Step 8: Format Partition with XFS Filesystem

```bash
sudo mkfs.xfs /dev/xvdbf1
```

This prepares the disk for use.

---

# 🔹 PART E — MOUNT THE EBS VOLUME

## Step 9: Create Mount Directory

```bash
sudo mkdir /mnt/lasyapriya
```

---

## Step 10: Mount the Volume

```bash
sudo mount /dev/xvdbf1 /mnt/lasyapriya
```

---

## Step 11: Verify Mount (Important)

```bash
df -h
```

Observation:

```
/dev/xvdbf1 mounted on /mnt/lasyapriya
```

This confirms successful mounting.

---

# 🔹 PART F — TEST DATA STORAGE (PROOF STEP)

## Step 12: Create Test File

```bash
cd /mnt/lasyapriya
sudo touch testfile
ls
```

Observation:

* testfile appears inside mounted directory
  This proves EBS storage is working.

---

# 🔹 PART G — PERMANENT MOUNT (VERY IMPORTANT)

## Step 13: Get UUID of the Volume

```bash
sudo blkid
```

Copy UUID of `/dev/xvdbf1`.

---

## Step 14: Edit fstab File

```bash
sudo nano /etc/fstab
```

Add the following line at the bottom:

```
UUID=YOUR-UUID  /mnt/lasyapriya  xfs  defaults,nofail  0  0
```

Save:

* Ctrl + X
* Press Y
* Press Enter

---

## Step 15: Apply and Verify fstab Entry

```bash
sudo mount -a
df -h
```

Volume should still appear mounted.

This ensures automatic mounting after reboot.

---

# 🔹 PART H — CREATE SNAPSHOT (BACKUP)

## Step 16: Create Snapshot of EBS Volume

1. Go to EC2 Dashboard
2. Click **Volumes**
3. Select the EBS Volume
4. Click **Actions → Create Snapshot**
5. Enter snapshot name
6. Click **Create Snapshot**

Snapshot is used for backup and disaster recovery.

---

# 📊 RESULT

The EBS volume was successfully created, attached to the EC2 instance, partitioned, formatted, mounted permanently using fstab, and a snapshot was created for backup.
